# privadosIA

Proyecto personal enfocado en herramientas de generación multimedia 100 % locales.

## mediaOrquestator

Un estudio generativo que corre en tu propia máquina para crear y gestionar **imagen, vídeo, música y animación**, con control de versiones y ejecuciones desde el navegador.

* **Arquitectura:** orquestador en **Go** (servidor y CLI), panel web en **Angular + Tailwind**, servicios especializados en **.NET (C#)** y **OpenAPI** como contrato único.
* **Web, ejemplos y demo (modo mock):** [orquestator.xuxo.net](https://orquestator.xuxo.net/)
* **Repositorio principal:** [privadosIA/mediaOrquestator](https://github.com/privadosIA/mediaOrquestator)

# privadosIA (English)

A personal initiative focused on 100% local generative media tools running on self-hosted hardware.

## mediaOrquestator

A self-hosted generative studio for **image, video, music, and animation**, with version tracking, run history, and browser-based management.

* **Architecture:** **Go** orchestrator (server + CLI), **Angular + Tailwind** web dashboard, **.NET (C#)** specialized services, and **OpenAPI** as the single API contract.
* **Website, examples & live mock demo:** [orquestator.xuxo.net](https://orquestator.xuxo.net/)
* **Main repository:** [privadosIA/mediaOrquestator](https://github.com/privadosIA/mediaOrquestator)
