# privadosIA

Proyecto personal de herramientas de generación multimedia que funcionan en tu propia máquina.

## Veritmo — ver el ritmo

Un estudio generativo local: convierte una canción en un **videoclip tipográfico** que va al compás, y además crea **vídeo, imagen, música y 3D**, todo gestionado desde el navegador y con historial de ejecuciones.

* **Arquitectura:** servidor y CLI en **Go**, panel web en **Angular + Tailwind**, servicios especializados en **.NET (C#)** y **OpenAPI** como contrato único.
* **Local por defecto:** los modelos corren en tu hardware (Linux con tarjeta NVIDIA). Usar un proveedor externo para el asistente es opcional y siempre lo decides tú.
* **Web, ejemplos y demo:** [veritmo.xuxo.net](https://veritmo.xuxo.net/)
* **Repositorio principal:** [privadosIA/veritmo](https://github.com/privadosIA/veritmo)

### Otros repositorios

* [dashboards-labs](https://github.com/privadosIA/dashboards-labs): el panel web.
* Ports a .NET de modelos de IA, para usarlos sin Python: [heartmula](https://github.com/privadosIA/heartmula), [DiffRhythm2](https://github.com/privadosIA/DiffRhythm2), [lion-clap](https://github.com/privadosIA/lion-clap), [musicgen-core](https://github.com/privadosIA/musicgen-core), [triposr](https://github.com/privadosIA/triposr) y [stable-fast-3d](https://github.com/privadosIA/stable-fast-3d).

Todo es Apache 2.0, salvo **stable-fast-3d**, que está bajo la Stability AI Community License.

# privadosIA (English)

A personal project building generative media tools that run on your own machine.

## Veritmo — see the rhythm

A self-hosted generative studio: it turns a song into a **kinetic-typography music video** that moves on the beat, and also makes **video, images, music and 3D**, all managed from the browser with a full run history.

* **Architecture:** **Go** server and CLI, **Angular + Tailwind** web dashboard, **.NET (C#)** specialised services, and **OpenAPI** as the single API contract.
* **Local by default:** models run on your hardware (Linux with an NVIDIA GPU). Using an external provider for the assistant is optional and always your choice.
* **Website, examples & demo:** [veritmo.xuxo.net](https://veritmo.xuxo.net/)
* **Main repository:** [privadosIA/veritmo](https://github.com/privadosIA/veritmo)

### Other repositories

* [dashboards-labs](https://github.com/privadosIA/dashboards-labs): the web dashboard.
* .NET ports of AI models, to use them without Python: [heartmula](https://github.com/privadosIA/heartmula), [DiffRhythm2](https://github.com/privadosIA/DiffRhythm2), [lion-clap](https://github.com/privadosIA/lion-clap), [musicgen-core](https://github.com/privadosIA/musicgen-core), [triposr](https://github.com/privadosIA/triposr) and [stable-fast-3d](https://github.com/privadosIA/stable-fast-3d).

Everything is Apache 2.0, except **stable-fast-3d**, which is under the Stability AI Community License.
